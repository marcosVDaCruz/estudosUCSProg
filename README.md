# 💻 Estudos de Programação em C — UCS

Repositório dedicado ao aprendizado e à prática da linguagem de programação **C**, desenvolvido durante minha graduação em **Ciência da Computação na Universidade de Caxias do Sul (UCS)**.

O objetivo deste repositório é registrar minha evolução acadêmica, organizar exercícios e documentar soluções desenvolvidas ao longo dos estudos de programação.

## 🎯 Objetivos

- Consolidar os fundamentos da linguagem C.
- Desenvolver o raciocínio lógico e computacional.
- Praticar a resolução de problemas por meio de algoritmos.
- Organizar exercícios e atividades desenvolvidos durante a graduação.
- Construir um histórico da minha evolução como estudante de Ciência da Computação.

## ▶️ Como compilar e executar

Para executar os exercícios, é necessário ter um compilador C instalado, como o GCC.

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse o diretório do exercício:

   ```bash
   cd estudos-programacao-c
   ```

3. Compile o arquivo desejado:

   ```bash
   gcc exercicio.c -o exercicio
   ```

4. Execute o programa:

   **Linux:**
   ```bash
   ./exercicio
   ```

   **Windows:**
   ```bash
   exercicio.exe
   ```

Substitua `exercicio.c` pelo nome do arquivo que deseja compilar.
